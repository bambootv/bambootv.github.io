Ứng dụng nào rồi cũng cần nhớ một thứ gì đó. Bài này ghi lại những gì mình học về cơ sở dữ liệu quan hệ.

## Bảng và quan hệ

- Khoá chính, khoá ngoại
- Quan hệ một-nhiều, nhiều-nhiều

## Câu lệnh SQL cơ bản

- `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- `JOIN` để ghép dữ liệu từ nhiều bảng
- `GROUP BY` để thống kê

## Chạy nhanh hơn

- Index là gì, khi nào nên thêm
- Lỗi N+1 câu truy vấn và cách tránh
