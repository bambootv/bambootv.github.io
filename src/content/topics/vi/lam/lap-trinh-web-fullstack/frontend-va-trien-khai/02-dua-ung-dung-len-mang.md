Code chạy được trên máy mình mới là một nửa. Nửa còn lại là để nó chạy ổn định ở nơi khác.

## Chọn nơi chạy

- Trang tĩnh: GitHub Pages, Netlify
- Có backend: VPS, Render, Fly.io

## Tự động hoá

- GitHub Actions: push là tự build và deploy
- Biến môi trường và bí mật

## Sau khi lên mạng

- Tên miền và HTTPS
- Xem log khi có lỗi
- Sao lưu cơ sở dữ liệu

> Blog này cũng chạy theo cách đó: viết Markdown, push lên GitHub, vài phút sau là bài lên mạng.
