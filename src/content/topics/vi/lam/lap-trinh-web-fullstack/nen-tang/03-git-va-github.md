Git là thứ mình ước được học sớm hơn. Có nó, mình dám thử và dám sai vì luôn quay lại được.

## Các lệnh dùng hằng ngày

- `git status`, `git add`, `git commit`
- `git log` để xem lịch sử
- `git push`, `git pull`

## Làm việc theo nhánh

- Tạo nhánh cho mỗi tính năng
- Pull request và review code
- Xử lý xung đột khi gộp nhánh

## Thói quen tốt

- Commit nhỏ, mỗi commit một ý
- Viết message nói rõ đã làm gì và vì sao
