Lúc mới học mình nhảy vào framework quá sớm và bị ngợp. Bài này liệt kê những gì nên nắm trước.

## Cú pháp cơ bản

- Biến `let`, `const`; kiểu dữ liệu
- Hàm, arrow function, tham số mặc định
- Mảng và các hàm `map`, `filter`, `reduce`

## Làm việc với trình duyệt

- DOM: chọn phần tử, đổi nội dung, bắt sự kiện
- Gọi API bằng `fetch`

## Bất đồng bộ

- Callback, Promise, `async`/`await`
- Lỗi hay gặp: quên `await`, không bắt lỗi

> Hiểu ngôn ngữ trước, framework sau. Framework thay đổi, ngôn ngữ thì ở lại.
