Trang web đầu tiên của mình chỉ có một tiêu đề và một tấm ảnh, nhưng đó là lúc mình hiểu trình duyệt đọc code như thế nào.

## Mình bắt đầu thế nào

- Công cụ: VS Code và trình duyệt Chrome
- Một file `index.html` duy nhất, mở thẳng bằng trình duyệt
- Nguồn học mình dùng (điền sau)

## HTML là bộ khung

- Thẻ có ý nghĩa: `header`, `main`, `article`, `footer`
- Link, ảnh, danh sách, bảng
- Form và các loại input

## CSS là quần áo

- Box model: margin, border, padding
- Flexbox và Grid để xếp bố cục
- Responsive bằng media query

## Bài tập tự làm

- Dựng lại trang giới thiệu bản thân, chạy được trên điện thoại
